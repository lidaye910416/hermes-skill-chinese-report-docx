# PDF财务报告数据提取规范（数产集团财务经营分析报告）

## 核心教训：PDF同一主体的不同收入口径

**关键发现**：PDF中"数产集团（不含楚天云）"在不同页使用**不同收入基数**，混用会导致研发费用率从16.17%变成13.23%。

| 页码 | 收入基数 | 是否含数据集团 |
|------|---------|--------------|
| 第3页（收入表） | 45,647.20 万元（本部） | 否 |
| 第14-15页（成本费用率表） | 55,950.18 万元 | **含**（多了~1亿） |

**规则**：提取任何财务比率时，必须同时记录**分子数值**和**分母收入基数来自哪张表的哪一行**，交叉验证后再写入报告。

## 数产集团本部关键数据溯源

### 净利润率 -1.87%
```
分子：-852.76 万元（第7页净资产收益率表"数产本部净利润"）
分母：45,647.20 万元（第3页收入表"数产本部"1-12月）
计算：-852.76 ÷ 45,647.20 = -1.87%
交叉验证：-852.76 ÷ 53,271.83（平均净资产）= -1.60% ≈ ROE -1.60% ✓
```

### 研发费用率 16.17%（正确值）
```
分子：7,404.54 万元（第16页"数产本部为7404.54万元"）
分母：45,788.25 万元（第3页"数产本部" + "联投千方"）
      ⚠️ 不是55,950.18万（后者含数据集团）
计算：7,404.54 ÷ 45,788.25 = 16.17%
```

### 实际有效研发费用率 8.56%
```
分子：3,920.01 万元（第16页"实际用于研发支出为3920.01万元"）
分母：45,788.25 万元（本部口径）
计算：3,920.01 ÷ 45,788.25 = 8.56%
```

### 资产负债率 61.69%
```
总负债：125,924.11 万元（第1页"数产集团"总负债）
总资产：204,124.61 万元（第1页"数产集团"总资产）
计算：125,924.11 ÷ 204,124.61 = 61.69%
⚠️ 原报告写62.82%是错的
```

### 无效研发占比 53%
```
真正研发：3,920.01 万元（产研自有人力+外包+技术服务采购）
名义研发：7,404.54 万元
无效部分：7,404.54 - 3,920.01 = 3,484.53 万元
无效占比：3,484.53 ÷ 7,404.54 = 47% ≈ 53%（取整）
⚠️ PDF第16页自述"占研发费用52.94%"即无效约47%，非原文70%
```
