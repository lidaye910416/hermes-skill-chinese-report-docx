## 核心写作特征（v10 调优依据）

| 维度 | 李博闻风格 | 等效 DeerFlow prompt 指令 |
|------|-----------|--------------------------|
| 问题口吻 | "一是在…二是…"平铺直叙 | "用平实口吻说武汉实际痛点，不写抽象概念" |
| 建议落地 | 明确提"武汉大学/华科/华为/曙光/浪潮" | "每条明确提具体机构，说'依托XX'落地表述" |
| 措施密度 | 短句密集，每点2-3个具体动作 | "每段至少含3个动作词（依托/联合/攻关/布局…）" |
| 技术定位 | 技术事实融在建议里，不单独成节 | "技术参数（如Cerebras/TurboQuant）放建议章节作支撑，不在问题章节空洞分析" |
| 结尾 | 无独立结语段，直接收束 | "不单独写结语，第二个建议章节最后一句即为收束" |
| 署名 | 执笔人：xxx（正文末尾） | "最后加一行'执笔人：xxx'" |

## 引言四要素（v10 实测确立）

引言必须同时覆盖：
1. **宏观背景**（1-2句）："数字经济正成为引领整体经济转型升级的新动能"/"国家层面在'十四五'期间明确提出'东数西算'工程"
2. **武汉具体数字**（核心）："武汉算力公共服务平台2024年7月上线一期，截至2025年2月已汇聚通算165万核、智算7909P、超算86P等资源"
3. **技术新浪潮**（1-2句）："以存算一体（Computing-in-Memory）为核心的技术新浪潮正在重塑全球AI芯片竞争格局"
4. **武汉优势锚定**（收尾）："武汉市若能立足自身光电融合优势…有望在新赛道上实现换道领跑"
